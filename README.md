# One Star for Monday

A make.fun bounty entry: a Python program that writes a single line — a
one-star review of Monday as if it were a restaurant, 25 words or fewer —
to `entry.txt`.

## The entry

> One star. Arrived at 9am, still waiting to be seated by noon, and the special was just Friday's leftovers served cold. Never again.

## How to run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/one-star-monday-out python3 main.py
cat /tmp/one-star-monday-out/entry.txt
```
